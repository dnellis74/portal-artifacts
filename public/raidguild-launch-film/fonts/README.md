# Grinder refined webfont provenance

These are Grinder-Refined-Regular.woff2, Grinder-Refined-Italic.woff2 and Grinder-Refined-Retalic.woff2 from raid-guild/website, `public/fonts/`, supplied by the project owner. The owner identifies them as conversions of Louchi’s corrected TTC package, fixing letter spacing. These supersede the older unrefined Grinder WOFF2s in this film.

The owner requested these exact files for the film and player headings. The player serves the supplied WOFF2 copies as website assets. This note records provenance and intended use; it does not grant a general font redistribution license. Do not bundle the proprietary fonts in the downloadable production-source archive or an unrelated font package.

For the editable film, copy the three files from `public/raidguild-launch-film/fonts/` into the study’s `assets/fonts/`. SHA-256 hashes of the exact corrected files are in `asset-manifest.json`.
